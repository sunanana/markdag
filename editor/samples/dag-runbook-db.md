# PostgreSQL 14 → 16

## 事前準備 %prep
- [ ] 互換性の確認
    > `pg_upgrade --check` を本番と同じ設定で実行し、エラーがないこと
- [ ] 拡張機能のバージョン確認
    > PostGIS と pg_stat_statements が 16 に対応した版であること
- [ ] 接続ドライバの確認
- [ ] 本番相当データでのリハーサル
    > 所要時間を測り、メンテナンス時間に 30 分以上の余裕があること
- [ ] 利用者への周知
- [ ] ロールバック手順の読み合わせ

## **実施判定** $go

## 停止 %day
- [ ] メンテナンス画面に切替
- [ ] バッチの停止
- [ ] アプリの書き込み停止
- [ ] 最終バックアップの取得
    > `pg_basebackup` の完了と、WAL のアーカイブが最新まで届いていること

## アップグレード %day
- [ ] スナップショットの作成
- [ ] pg_upgrade の実行
    > `pg_upgrade --link` を使う。旧クラスタは起動しない
- [ ] 統計情報の再取得
    > `vacuumdb --all --analyze-in-stages`
- [ ] レプリカの再構築

## 検証 %verify
- [ ] 行数の突き合わせ
- [ ] 主要クエリの実行計画の比較
- [ ] アプリのスモークテスト
- [ ] 監視メトリクスの確認

## **切替判定** $switch

## 再開 %day
- [ ] アプリの書き込み再開
- [ ] バッチの再開
- [ ] メンテナンス画面の解除

## **作業完了** $done

## ロールバック %rollback
- [ ] 旧クラスタの起動
    > `--link` で起動していない旧クラスタのデータディレクトリをそのまま使う
- [ ] 接続先を旧クラスタへ戻す
- [ ] 差分データの確認
