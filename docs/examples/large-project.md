# 新サービス立ち上げ

## 企画 %plan

### 市場調査 %research
- [x] 競合サービスの棚卸し
    > 同じ価格帯の 8 サービスを、機能と料金で並べた。
    >
    > - 比較軸: 料金、無料枠、対応端末、サポート
    > - 出典は各社の公開ページのみ
- [x] ユーザーインタビュー
    > 見込み客 12 人に 45 分ずつ聞いた。
    >
    > - 聞いた層: 個人事業主 7 人、小規模チーム 5 人
    > - 録音と書き起こしは共有ドライブに置いた
- [x] アンケート集計
- [x] 市場規模の試算

### 要件定義 %requirement
- [x] ペルソナ定義
    > 主要な 2 人を決めた。
    >
    > - 個人で使う人: 記録の速さを最優先
    > - チームで使う人: 共有と権限を最優先
- [x] ユーザーストーリーの洗い出し
- [x] 受け入れ条件の定義
- [x] 非機能要件の整理
    > 落とせない条件だけを 5 つに絞った。
    >
    > - 表示は 2 秒以内、同時 500 人
    > - 個人情報は国内リージョンに置く
